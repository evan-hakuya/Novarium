# 第一个刮削源用 DaoSearch，密钥存在数据库中

刮削第一版只接 DaoSearch 的只读 JSON API，不直接抓起点、番茄等源站页面。直接抓页面要应对改版和反爬（限速、熔断、浏览器回退），Cloudflare Workers 的出口 IP 容易被拦截，也不能运行浏览器；DaoSearch 覆盖九个平台，字段有文档且 v1 内只增不减。刮削源做成可替换的接口，以后发现其他刮削源时新增实现即可。

DaoSearch 的 API 密钥由所有者在后台设置页填写，保存在数据库的设置中，页面只显示前后几位。这样 Cloudflare 与 Docker 用同一个入口，换密钥不需要重新部署；代价是数据库泄露时密钥也会泄露，与访问令牌明文存储（ADR 0004）的风险相同，在 DaoSearch 账号页重新生成即可止损。

DaoSearch 的条款要求展示其数据的地方附上该书在 DaoSearch 的链接，因此后台书详情页显示链接，书源返回的简介末尾附「资料来源：DaoSearch」与链接。

## Considered Options

- 参考 inovel-server 直接抓源站：维护成本高，Workers 上大概率被拦截；其代码许可为「个人使用，按需自改」，不能复制进 MIT 项目。
- 密钥放在环境变量或 secret：更安全，但每次更换都要改部署配置，一键部署还要多填一项。
